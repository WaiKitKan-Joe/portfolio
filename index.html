Quantitative Finance

Netflix Stock-Price Simulation Using the Heston Model

Stochastic volatility modelling and Monte Carlo simulation

A Heston stochastic-volatility simulation of Netflix stock prices, with 50,000 paths, return and terminal-price distributions, scenario percentiles, Value at Risk and Expected Shortfall.

Methodology

  • Prepared historical Netflix closing-price data.
  • Estimated stochastic variance parameters from rolling volatility.
  • Simulated correlated price and variance processes.
  • Evaluated a 10-business-day investment horizon.

Project Outputs

  • Simulated stock-price paths.
  • Terminal-price and return distributions.
  • Percentile-based scenarios.
  • VaR, Expected Shortfall and probability-of-profit analysis.

Fixed Income and Econometrics

U.S. Treasury Yield Forecasting

Yield-curve factors, AutoReg modelling and expanding-window backtesting

A forecasting project for the 10-year U.S. Treasury yield using DGS10, DGS5, DGS2 and DGS1MO factors. The project compares a four-factor OLS model with AR(10) and an unchanged-yield benchmark over a 10-observation forecast horizon.

Methodology

  • Retrieved Treasury yield data directly from FRED.
  • Estimated a four-factor OLS forecasting model.
  • Applied Ljung-Box, White and HAC diagnostic procedures.
  • Backtested OLS and AR(10) models using expanding estimation windows.

Key Findings

  • Latest DGS10 forecast: 5.0322%.
  • Estimated 71.12% probability that DGS10 exceeds 4.955%.
  • Factor-model OOS R²: −31.1357%.
  • AR(10) OOS R²: −67.0541%; the persistence benchmark performed best.
